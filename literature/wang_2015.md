# Wang, Mahulea & Silva — Diagnosis of Time Petri Nets Using Fault Diagnosis Graph

* X. Wang, C. Mahulea, M. Silva, IEEE Trans. Automatic Control 60(9), 2015,
  DOI 10.1109/TAC.2015.2405293.
* Full-text status: journal PDF not open access. The **author's PhD thesis**
  (X. Wang, *Discrete event system tools for fault diagnosis and collision
  prevention*, Univ. Zaragoza, 2016, `http://webdiis.unizar.es/~cmahulea/papers/PhD_Xu_Wang.pdf`)
  contains the same model, state classes, firing-domain algorithm and Example
  4.1; it was fully read. The journal DOI is the citation of record, and the
  reproduced numbers are cross-checked against the official `wangTAC.net`.
* Official model: `https://projects.laas.fr/twina/files/wangTAC.net`.

## Model & semantics

7 places, 7 transitions, 18 arcs; initial `p1 + 2p2`. TPN with static
intervals, observable/unobservable partition and one unobservable fault
eps4 (`.net` t3, label f). Strong-time semantics (firing rule: enabled `t` may
fire after `θ` with `ν(t)+θ ∈ [e_t,l_t]`, and for every enabled `u`,
`θ ≤ l_u − ν(u)`). Single-server.

## Definitions used

* **State class** `α = (m, F)`, `F` a firing domain over the firing dates of
  enabled transitions; constructed by Berthomieu–Menasche style successor
  (persistent clocks keep dates, newly enabled reset).
* **Firing domain of a firing sequence** `[g_l,g_u]`: min/max of the last
  firing variable subject to the LPP built by thesis Algorithm 4.1. Steps:
  enableness interval of each transition, constraints for transitions
  disabled by the firing, and constraints that every still-enabled unfired
  transition must not overrun its latest bound (`y4 − y1 ≤ 4` in Example 4.1).
* **Fault Diagnosis Graph (FDG)**: SCG pruned to nodes/edges useful for
  diagnosis, edge labels carry firing domains; built incrementally.

## Usability for the 12 criteria

SCG/firing-domain correctness reference: PASS. Manufacturing semantics, task
completion, resource contention: FAIL (abstraction has no process meaning).
Observable/unobservable + fault: PASS. Time competition: PASS. Cycles: yes
(p2→p5→p7→p2). Recommendation: use as the **formal SCG benchmark**, not as
the industrial example.
